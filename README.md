# site-placeholder

Reusable static placeholder page for websites and project domains.

Current deployment content: **AI В ДЕЛО**.

## Files

- `index.html` — page structure and current project copy.
- `styles.css` — responsive visual design.

## Reuse

To adapt the placeholder for another project, replace:

- page title and meta description;
- brand name and tagline;
- main heading and lead text;
- benefit labels and descriptions;
- footer text;
- CSS palette variables in `:root` if a different visual identity is required.

The page has no JavaScript or external runtime dependencies and is suitable for static hosting such as GitHub Pages.
